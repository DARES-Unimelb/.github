# 双发固定翼测试平台：设计基准与尺寸推导

对应参数集 `params/uacs_twin_params.m`，`meta.revision = 7`，日期 2026-10-10。

本文件说明每个设计数字**从哪来、被什么约束、可信到什么程度**。参数集里每一项都标了 MEASURED / SIZED / ESTIMATE，这里是那张标记表的展开。

## 1. 输入约束

| 约束 | 值 | 来源 |
|---|---|---|
| 总宽（翼展）上限 | 3.50 m | 团队要求，硬约束，`init` 有断言 |
| 起飞质量 | 20.0 kg | 团队要求（载荷 12 kg 是其中一项） |
| 巡航速度 | 25.0 m/s | 本平台选定 |
| 续航 | 20 min | 团队要求，非核心指标 |
| 构型 | 双发上单翼，左右机翼各一桨，反向旋转 | 团队要求 |
| 操纵面 | 副翼 + 升降舵 + 方向舵 + 双油门 | 团队要求 |

翼展 3.5 m 是所有几何推导的**主动约束**，下面几乎所有"意外"结论都源于它。3.4 m 取在限制内 0.1 m。

## 2. 机翼与翼载

翼展定死后，机翼还剩两个自由度：面积与展弦比。面积由翼载决定，展弦比由结构决定。

```
翼载  W/S = 196.13 / 2.312 = 84.8 N/m²
失速  V_s = sqrt(2W/(rho*S*CL_max)) = 10.20 m/s
```

面积取 2.312 m²（展弦比 5.0）的理由是**低速可配平性**，见第 5 节。展弦比从最初的 5.8 降到 5.0 是一次被迫的交换：

- 展弦比 5.8 时面积 1.993 m²，翼载 98.4 N/m²，失速 11.0 m/s，但**升降舵只能配平到 16.2 m/s 以上**，低速边界很紧；
- 展弦比 5.0 时面积 2.312 m²，翼载降到 84.8 N/m²，配平边界放宽到 16.18 m/s。

代价是升阻比：巡航 L/D 从 7.42 降到 **6.52**。这是真实的损失，换来的是低速可控。**如果后续确认不需要在 16–18 m/s 区间飞，可以把展弦比提回去换效率。**

## 3. 质量与惯量

`P.mass.items` 是一张 12 行的质量表，含站位（x, y, z），`P.mass.m` 必须等于表内求和，`init` 有断言。

点质量求和后再乘一个分布因子，因为质量表给的是集中站位，而真实结构是分布的：

```
Ixx = 1.9859   Iyy = 4.5429   Izz = 5.8069   Ixz = -0.0824   kg*m²
CG  = x -0.00923 m（在参考原点之前约 1.4% 平均气动弦）
```

**这一项是当前最大的已知缺陷。** 机翼 3.20 kg 全部记在 y = 0，展向只有电机在 y = ±0.9，导致 `Ixx` 偏小。机翼单按均布计算就有 `m*b²/12 = 3.08 kg·m²`，比现在的 `Ixx` 总量还大；换成真实分布后：

| 量 | 现值 | 修正估计 | 后果 |
|---|---|---|---|
| `Ixx` | 1.986 | 约 5.1 | 滚转沉降时间常数 0.025 → 约 0.075 s |
| `Izz` | 5.807 | 约 8.9 | 荷兰滚固有频率 7.6 → 约 6.8 rad/s |

**后果**：V4 判据里"滚转沉降时间常数 < 1 s"这一条对当前惯量估算**没有区分度**，任何结果都会通过。要等结构组给出真实质量分布或 CAD 惯量后再当判据用。判据表里已按此标注。

## 4. 尾翼：一次被迫的妥协

### 4.1 两个要求互相冲突

平尾面积同时进入两个互相拉扯的量：

```
静稳定余量   SM = -Cm_alpha/CL_alpha - x_cg/cbar      ∝ Sh      （线性）
升降舵权限   Cm_de = -tau*CL_alpha*(Sh/S)*Vh*(lh/cbar) ∝ Sh²   （平方）
```

平尾越大，静稳定余量越大（飞机越"死"），但升降舵权限涨得更快，低速越配得平。反过来压小平尾去凑好看的静稳定余量，低速就配不平。

### 4.2 整个组合空间内无解

做过一次直接搜索：展弦比 4.2 到 7.5（步长 0.1）、平尾面积比 6% 到 30%（步长 0.5%），条件为

- 静稳定余量 ≤ 30%
- 16 m/s 处配平舵偏 ≤ 半个行程

**没有任何一组同时满足。** 这不是调参没调好，是这套翼载与翼展组合的固有性质。

所以：**平尾按配平需求定尺，静稳定余量作为结果报出**，不再当目标。

```
平尾面积比 Sh/S = 0.100  ->  Sh = 0.2312 m²,  Vh = 0.28676
结果静稳定余量  SM = 29.6% cbar
```

29.6% 比常规飞机（5–15%）大不少，属于"很稳但不灵活"。因为有 PID/LQR 增稳，这个余量是**可以接受的**，但代价是俯仰响应迟钝，必须靠控制律补。**想真正降下来，只有降翼载或减重，改尾翼是死路。**

### 4.3 根因

3.4 m 翼展背 20 kg。翼载 84.8 N/m²，失速 10.2 m/s，低速飞行时迎角很大，尾翼要把这个迎角力矩配掉，就需要很大的平尾，而平尾一大静稳定余量就上去了。**这是小翼展大重量的必然结果。**

## 5. 低速边界由配平决定，不由失速决定

这一条是本次推导最反直觉、也最该记住的结论。

```
失速口径    V_stall * 1.20         = 12.246 m/s
配平口径    80% 升降舵行程处可配平 = 16.184 m/s
实际 V_min = max(两者)             = 16.184 m/s
```

在 16.18 m/s 处升降舵已经用掉 80% 行程，而失速还有 37% 的余量。**如果按失速报最低速度，会报出一个飞机根本配不平的速度。**

全包线配平舵偏：

| V (m/s) | 16.2 | 18 | 20 | 22 | 25 | 30 | 35 |
|---|---|---|---|---|---|---|---|
| 升降舵 (deg) | −20.0 | −13.4 | −8.1 | −4.2 | **0.0** | +4.4 | +7.1 |
| 占行程 | 80% | 54% | 32% | 17% | 0% | 18% | 28% |

巡航点配平舵偏为 **0 度**，这是设计目标：零配平阻力。做法是不手填 `Cm0`，而是由尾翼安装角与下洗反推出来（`Cm0 = +0.00045`）。

## 6. 推进

油门定义为**峰值轴功率的份额**，不是推力的份额。推力由动量理论从功率解出：

```
P_shaft = throttle^(2/3) * P_shaft_peak        P_shaft_peak = 3500*0.88*0.95 = 2926 W
P_ideal = P_shaft * FM                          FM = 0.55
静止  T = (P_ideal*sqrt(2*rho*A))^(2/3)         -> 93.716 N 每电机
前飞  解 P_ideal = 2*rho*A*v_i*(V+v_i)^2 得 v_i，T = 2*rho*A*v_i*(V+v_i)
```

由此推出 `T ∝ throttle^(4/9)`，不是 `2/3`。`T ∝ P^(2/3)` **只在静止成立**，前飞时指数趋近 1。

| 量 | 值 |
|---|---|
| 静推 / 静推重比 | 93.716 N 每电机 / 0.956 |
| 巡航推力 / 电功率 / 油门 | 30.10 N 总 / 1250 W / 0.1253 |
| 全油门 25 m/s 可用推力 | 52.84 N 每电机 |
| 平飞极速 | 41–42 m/s |
| 20 min 能量 / 电池（200 Wh/kg, 80% DoD） | 417 Wh / 2.60 kg |

静推重比 0.956 意味着**不能垂直爬升**，这是固定翼的常态，不是缺陷。峰值电功率 7.0 kW（350 W/kg）对 20 kg 机是健康的。

电池 2.60 kg 按 200 Wh/kg 与 80% 放电深度估算，这两个都是**假设**，需用电芯实际数据替换。

## 7. 控制权限（巡航点，q = 383 Pa）

| 通道 | 满偏力矩 | 说明 |
|---|---|---|
| 方向舵 偏航 | 50.11 N·m | 几何交叉核对：侧力 25.70 N × 力臂 1.95 m |
| 副翼 滚转 | 54.10 N·m | |
| 升降舵 俯仰 | 65.27 N·m | |
| 差动推力 偏航 | 21.13 N·m | 方向舵的 42.2%，**受油门余量限制** |
| 单发失效 偏航 | 84.34 N·m | **方向舵的 1.68 倍** |

### 7.1 差动推力的可用权限只有结构上限的六分之一

结构上限 `d_cap = 0.60` 是永远达不到的。巡航油门只有 0.1253，对称调制时"低油门那台不能低于怠速、总推力还得保持不变"这条约束把可用量卡在 ±0.1253。所以：

```
可用  21.13 N*m（42.2% 方向舵）
结构上限 101.2 N*m（202% 方向舵，巡航不可达）
```

**报告里必须用可用值。** 按结构上限报会高估 4.8 倍。低速时油门余量大，差动推力才真正管用——这也是差动推力在起飞/着陆阶段比巡航更有价值的原因。

### 7.2 单发失效：不能保持巡航

满油门单发偏航力矩是方向舵权限的 1.68 倍，`V_mc = 32.43 m/s`，**高于巡航 25 m/s**。所以：

- **25 m/s 巡航时单发失效，方向舵压不住满油门的那台。** 正确处置是立刻收另一台油门并下降，不是抢高度。
- 在 32.43 m/s 以上单发可以配平。
- 单发低头力矩 11.10 N·m，占升降舵满偏的 17%，可控。

这条不是缺陷而是设计边界，但必须写进失效处置程序。

## 8. 气动系数：来源与可信度

**没有风洞、没有 CFD、没有飞行辨识**，所以下表里所有气动导数都是**工程估算**。几何派生量（尾容量、`Cm_alpha`、`Cm_de`、`Cm_q`、`Cn_beta`、`Cn_r`、`Cn_dr`）是自洽的，因为它们由几何与三个原始系数算出，改几何会跟着动；原始系数是估的。

| 系数 | 值 | 可信度 | 依据 |
|---|---|---|---|
| `CL_alpha` | 4.65 /rad | 中 | 有限翼展估算，薄翼理论 6.28，展弦比 5 修正 |
| `CL0` | 0.22 | 中 | 对应约 2.7 度零升迎角，常规翼型 |
| `CD0` | 0.030 | 中 | 双发上单翼、固定起落架的常规量级 |
| `e_oswald` | 0.78 | 中 | 展弦比 5 的常规值 |
| `CM0_wing` | -0.012 | 低 | 凸翼型绕气动中心的常规量级 |
| `CY_beta` | -0.75 | **低** | 垂尾侧力，未做风洞 |
| `Cl_beta` | -0.090 | **低** | 上单翼加 3 度上反 |
| `Cn_beta` | +0.11163 | 中（派生） | 由 `Vv` 与 `CY_beta_tail` 派生 |
| `tau_elevator` / `tau_rudder` | 0.65 / 0.50 | 中 | 襟翼效率经验值，随弦长比 |

**交叉核对**：与公开的 Aerosonde 模型（BYU MAGICC mavsim，`docs/aerosonde_parameters.m.txt`，真实飞机数据）逐项对照，`CY_beta`、`Cn_beta`、`Cl_p`、`Cd0`、`CL_alpha` 的量级都落在同一档。`Cn_dr/Cn_beta` 比值我们是 0.342，Aerosonde 是 0.945，差异来自舵面积比，已在文件里注明。

**最该优先替换的三个**：`CY_beta` 与 `Cl_beta`（全靠估，直接决定横航向品质）、`CD0`（直接决定航时与油门）。

## 9. 参数定了之后怎么灌入

改哪些字段、跑什么、看什么：

1. **外形定了**：改 `P.geom` 的 `b`、`AR`、`Sh_over_S`、`Sv`、`lh`、`lv`、各舵面弦长比。面积、平均气动弦、尾容量、以及所有几何派生的气动导数**全部自动跟着变**。
2. **马达与桨定了**：改 `P.prop` 的 `D`、`pitch_in`、`rpm_static`、`power.peak_per_motor_W`、`power.figure_of_merit`。静推、速度推力表、`z_thrust_offset_max` 自动重算。
3. **质量与配重定了**：改 `P.mass.items` 那张表（含站位），惯量与 CG 自动重算。
4. **跑**：`init_uacs_twin` → 断言全部通过 → `run_job('plant_baseline')` → `run_job('control_design')` → `run_job('sim_build_models')`。
5. **看**：`init` 的断言会直接拦住不自洽的组合。特别会拦：翼展超限、质量表与总重不符、静稳定余量出界、低速配平行程不够、单发俯仰超预算、`V_min` 低于可配平速度、气动系数符号错。
6. **递增 `meta.revision`**，否则前后两次测量无法区分。

**这套流程的意义**：外形与马达一旦定案，改参数、重跑、拿配平与增益，不需要改任何代码。
