## 2. 实现的方程

状态与输入顺序、符号约定全部照 `architecture.md` 第 4 节，不另立一套。

气动：`qbar = 0.5*rho*V^2`；迎角取 `atan2(w,u)`；侧滑取 `asin(v/V)` 并做数值限幅。升力、阻力、侧力、三个力矩系数按共用方程实现，唯一的补充是阻力第二项里的零升迎角取 `alpha0 = -CL0/CL_alpha`，由升力线自身推出来，不引入新常数。

风轴到机体：用团队共用的小迎角小侧滑形式。

推力：`T = prop_thrust_from_throttle(P, throttle, V)`，油门是峰值轴功率的份额，前进比效应由动量理论解诱导速度得到。

六自由度：牛顿欧拉，重力在机体系施加，转动惯量保留 `Ixz` 交叉项，即 `I = [Ixx 0 -Ixz; 0 Iyy 0; -Ixz 0 Izz]`，与教科书三轴力矩方程逐项等价。

欧拉角运动学用 `tan(theta)` 与 `1/cos(theta)`，位置状态用机体到 NED 的方向余弦矩阵。

## 3. 建模决策与近似，逐条给实测量级

### 3.1 Cm_alphadot 用 alpha_dot = q

`aero_forces` 的签名没有 alpha_dot，用有限差分需要上一时刻的迎角，用 persistent 会破坏 `ode45` 与 Simulink 的无状态契约。首版取平飞运动学恒等式 `alpha_dot = q - gamma_dot` 在 `gamma_dot = 0` 时的形式，即 `alpha_dot = q`，等价于把俯仰阻尼从 `Cm_q = -4.1536` 增强到 `Cm_q + Cm_alphadot = -6.6536`。

量级用实测 A 矩阵算：从巡航 A_long 去掉这一项对 `A(3,3)` 的贡献 -2.8857，得到替代读法 `alpha_dot = 0` 的短周期为固有频率 9.4730 rad/s、阻尼频率 7.3430 rad/s、阻尼比 0.6318，而实测读法为 10.5071、7.4348、0.7066。差别是固有频率 -9.84%、阻尼比 -10.59%、阻尼频率 -1.23%。**两种读法都不改变任何一条判据的结论**：固有频率两种读法都在 2..8 rad/s 之外，阻尼频率两种读法都在窗口之内，阻尼比两种读法都通过。`dbg.Cm_q_eff` 与 `dbg.alphadot_law` 会把这个选择写在返回值里。

### 3.2 密度取常数

`flow_state` 用 `P.env.rho_sl`，不做密度高度修正。理由：`P` 里没有温度与温度梯度字段，要写 ISA 就必须在脚本里硬编码 288.15 K、0.0065 K/m、287.05，这违反 `architecture.md` 第 3 节。代价可量化：150 m 处 ISA 密度比海平面低 1.43%，巡航所需升力系数随之偏大 1.4%，配平迎角变化约 0.002 度。

### 3.3 力矩参考点，当前已是一阶项

气动力矩直接取机体系分量，即把 `aero_forces` 的 `M_body` 当作绕重心。参数文件把 `Cm0` 与 `Cm_alpha_wing_body` 标注为绕参考原点（机翼气动中心），两者口径不一致。

在改小平尾之前这条可以忽略，现在不能：`Cm_de` 只有 -0.050294，气动中心到重心的平移量 `dCm = -CL*(x_ac - x_cg)/cbar = -0.25696*0.009225/0.586207 = -0.004043`，换算成升降舵是 4.61 度，占巡航配平舵偏 12.39 度的 37%。**建议 Lead 定一个口径**：要么承认系数就是绕重心的，要么在 `aero_forces` 里加平移项，改动只有一行，但配平舵偏会从 12.39 度降到约 7.78 度，直接影响 T2 的舵面权限预算。

### 3.4 推力线力臂

竖直力臂取 `P.prop.z_thrust_offset`，横向与纵向力臂取 `x_motor - x_cg` 与 `y_motor - y_cg`。实测 `z_thrust_offset` 与 `z_motor - z_cg` 的差为 0.000e+00 m，2026-10-08 那个 0.16 m 的独立输入值已经改成派生量。

巡航推力俯仰力矩 3.3491 N·m，占总俯仰配平的 `dCm = 0.007488`，等效升降舵 8.53 度。这一项与 `Cm0` 同号，是巡航舵偏大的原因之一。

### 3.5 dT 通道

`u(6)` 是加性对称推力增量，左右各加一半。实测 `(B(:,4)+B(:,5))/(2*dT/dthrottle)` 与 `B(:,6)` 的相对差为 1.388e-09，两者逐元素一致：`B(:,6) = [0.05; 0; 0; 0; -0.0260737; 0; 0; 0; 0; 0; 0; 0]`。这说明 dT 与油门通道在物理上是同一路执行机构，LQR 用 dT 设计出的增益可以按局部斜率 78.4969 N 每单位油门换算回油门。

### 3.6 首版不建模的东西

反扭矩与 P 因子（对转桨抵消）、螺旋桨滑流增益、非定常下洗、压缩性、失速与 `CL_max` 限制、伺服与 ESC 动态、地面效应、阵风。

### 3.7 配平

未知量 `[alpha, de, throttle]`，左右油门相同。方程取 `Fx = 0`、`Fz = 0`、`My = 0`，约定 `beta = da = dr = 0`、`phi = 0`、`theta = alpha + gamma`，平飞时 `theta = alpha`，爬升时两者相差 `gamma`。有坡度的配平明确报错，不返回不平衡的解。

残差归一化：力除以 `m*g = 196.133 N`，力矩除以 `qbar*S*cbar`，两者在报告里逐工况打印。判据 V2 用 6 维归一化残差的最大绝对值。残差由 `eom_6dof` 的第二个与第三个输出给出，不另写一套力与力矩。

初值由解析式给：升力系数反解迎角、俯仰平衡反解升降舵、对权威推进映射做二分反解油门。三个工况都是 6 次迭代、25 到 28 次函数求值收敛，`exitflag = 4`，一阶最优性 1e-15 量级。

### 3.8 线性化

中心差分，步长规则 `h_i = step*max(1,|x_i|)`，`step = 1e-6`，角度与角速率因此得到 1e-6 rad 与 1e-6 rad/s，速度状态得到 2.5e-5 m/s。

步长研究实测，与 1e-6 结果比：步长 1e-4 时 A 的相对 Frobenius 差 9.973e-10、B 差 1.868e-08；1e-5 时 2.725e-11 与 1.860e-10；1e-7 时 4.458e-10 与 3.283e-11。四档步长给出的短周期频率与阻尼比在打印的 6 位有效数字上完全相同，说明 1e-6 已在雅可比的收敛平台上，取它作默认步长是安全的。

子矩阵只从 `lin.A` 与 `lin.B` 抽取，索引写死在 `linearize_at` 里并打印：

```
纵向 A_long = A([1 3 5 8],[1 3 5 8])  状态 [u w q theta]   输入 B_long = B([1 3 5 8],[2 6])   [de dT]
横航 A_lat  = A([2 4 6 7],[2 4 6 7])  状态 [v p r phi]     输入 B_lat  = B([2 4 6 7],[1 3])   [da dr]
```

`u` 当作 `V` 的替代状态：巡航迎角 0.1554 度，`u = V*cos(alpha)` 与 `V` 的相对差 3.68e-6。

`C = eye(12)`、`D = zeros(12,6)`，12 个状态全部作为输出，无前馈。

模态的 `freq_rad_s` 取极点模，与 Control System Toolbox 的 `damp` 口径一致，即固有频率；同时另存 `freq_damped_rad_s` 与 `freq_nat_rad_s`。对本平台判据很关键，5.2 节展开。

迎角诊断：巡航速度 25 m/s、总重 196.13 N、机翼面积 1.9931 m² 时所需升力系数只有 0.25696，翼载 98.4 N/m²。现行窗口下沿 2 度对应 `CL = 0.38232`，要压进这个下沿必须满足三者之一：速度降到 20.50 m/s 以下，或机翼面积降到 1.3401 m² 以下，或总重加到 29.75 kg 以上。这三者都是外形、质量与巡航速度的联合定义问题，不是模型问题。**该改的是窗口，不是模型**，建议按 0..8 度重定并写明理由。

### 5.2 慢速点不可配平，本条是本轮最重的发现

慢速点 18 m/s 配平需要升降舵 -42.81 度，超出 `P.act.elevator.max_deg = 25` 度。fsolve 在数学上仍然收敛，残差 7.7e-18，但这个解物理上做不到。

根因是升降舵俯仰权限对平尾面积是二次的：`CL_de = tau_e*CL_alpha*Sh/S` 与 `Vh = Sh*lh/(S*cbar)` 都正比于 `Sh`，而 `Cm_de = -CL_de*Vh*(lh/cbar)` 因此正比于 `Sh` 的平方。当前参数把平尾按静稳定裕度目标派生：`SM_target = 0.15` 给出 `Vh = 0.134263`、`Sh = 0.080456 m²`、`Cm_de = -0.050294`。同一套公式在 `Sh = 0.270 m²` 时给出 `Cm_de = -0.5666`，相差 11.3 倍，正好是面积比的平方。

同一份代码在 09:22:41 那次运行里用的是 24630 字节的旧参数（`Sh = 0.270`、`Vh = 0.4506`），慢速点舵偏是 -16.08 度，巡航是 -0.50 度；换成静稳定裕度派生的平尾后，慢速点变成 -42.81 度、巡航变成 +12.39 度。要恢复慢速点可配平，按 `de` 大致反比于 `Sh` 估算需要 `Sh` 回到约 0.138 m² 以上，对应 `Vh` 约 0.23、`SM_target` 约 0.246。另一个方向是把慢速检查点抬高到 20 m/s 以上并降低 `V_min` 的承诺，或者允许更大的作动权限。这条需要 Lead 与总体定，不是对象模型能单方面决定的。

## 6. 最不可信的三个系数

按对判据与舵面预算的影响排序。全部只提建议，不擅自改值。

1. `geom.SM_target = 0.15` 及其派生的 `geom.Sh = 0.080456 m²`。它决定 `Cm_de = -0.050294`，而升降舵权限对平尾面积是二次的，于是巡航要用掉 12.39 度、慢速点要 -42.81 度，后者超出 25 度作动限幅，等于低速不可配平。静稳定裕度本身是设计目标，但当前取值没有与升降舵权限、`V_min` 承诺一起校验。建议把「在 `limits.V_min_mps` 处配平舵偏不超过作动限幅的 80%」写成一条派生断言放进 `init`，让下一次改平尾时立刻报错。按现有数据，`Sh` 需要回到约 0.138 m² 才能让 18 m/s 可配平。

2. `mass.Ixx_cg = 1.985868 kg*m^2` 与 `mass.Izz_cg = 5.806915 kg*m^2`。惯量由 `mass.items` 的点质量加一个全局分布因子凑出来，机翼 3.2 kg 的 y 坐标写在 0，于是机翼对这两个惯量几乎没有贡献。把 3.4 m 翼展的机翼按均布质量算，单它一项就是 `m*b^2/12 = 3.08 kg*m^2`：`Ixx` 会涨到约 5.1，滚转沉降时间常数从 0.0291 s 变成约 0.075 s；`Izz` 会涨到约 8.9，荷兰滚固有频率按 `1/sqrt(Izz)` 掉约 19%，从 8.42 掉到约 6.8 rad/s。荷兰滚阻尼比的判据结论不变，但 T2 的滚转与偏航带宽目标会跟着变。**这是全平台最该用 CAD 或实测惯量替换的一条。**

3. `aero.Cm0 = 0.020`。在改小平尾之后它成了巡航俯仰配平的主导项：巡航俯仰方程里 `Cm0 = +0.020` 对上机翼 -0.00164、推力 -0.007488、升降舵 -0.010872，也就是说 89% 的抬头预算来自 `Cm0`。它同时是 3.3 节那条参考点口径争议的核心：如果它按字面是绕机翼气动中心的，移到重心后配平舵偏会从 12.39 度降到约 7.78 度，差 4.61 度，占现有舵偏的 37%。建议要么把口径写死为绕重心，要么补平移项，然后再谈这个值本身该是多少。

补充两条不列前三但要知道：`aero.Cl_beta = -0.090` 让螺旋稳定在时间常数 9.38 秒，垂尾再加大或副翼权限再减小都可能推回发散；`prop.power.figure_of_merit = 0.55` 是静推力唯一的效率输入，静推力与它成 2/3 次方关系，0.05 的误差带来 6% 的静推力误差，直接进单发失效偏航力矩。
