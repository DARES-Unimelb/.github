# 控制律设计说明（LQR 与 PID 级联）

本文件说明 `MATLAB/control/` 下四个交付函数的设计判据与做法。数值结果见 `results/control_lqr_report.txt`、`results/control_pid_report.txt`、`results/control_allocation_report.txt` 与 `results/gains_baseline.mat`。接口以 `docs/architecture.md` 为唯一权威。

## 2. 坐标口径（最容易出错的一处）

`linearize_at` 抽出的纵向子矩阵状态是机体分量 `[du dw dq dtheta]`，横航向是 `[dv dp dr dphi]`。契约的口径是 `[dV dalpha dq dtheta]` 与 `[dbeta dp dr dphi]`。两者在 alpha 通道上差一个 `V0`，直接拿按 `dalpha` 设计的 Bryson 权重去乘 `dw` 会错约 25 倍。

`lin_contract.m` 做精确变量替换：

```
dV     =  cos(a0)*du + sin(a0)*dw
dalpha = -sin(a0)*du/V0 + cos(a0)*dw/V0
dbeta  =  dv/V0                  (flow_state 定义 beta = asin(v/V))
```

替换只做一次，用到的 `V0` 与 `a0` 来自 `lin.x_star`，并以 `lin.long_state_names` 判断是否已经是空气数据状态，是则跳过。报告里写明用了哪个分支。

**同一个偏导在两套基底下差 `V0`，看起来像"数值变了"其实没变。** `linearize_at` 返回机体轴，`lin_contract` 返回契约轴，两者对同一个量给出不同的数字：

| 量 | 机体轴（`linearize_at` 的 `lin.B`） | 契约轴（`lin_contract` 的 `lc.B_long`） |
|---|---|---|
| 升降舵到前向 | `du/de = -0.387497` | `dV/de = -0.254243` |
| 升降舵到垂向 | `dw/de = -25.175727` | `dalpha/de = -1.007097` |
| 升降舵到俯仰角加速度 | `-216.197` | `-216.197`（不变） |

第 2 行两列之比是 `24.998314`，`V0 = 25.000000`，`V0` 因子就是全部差别；两列之间用 `T_long` 互转的残差是 `0.000e+00` 与 `2.22e-16`。`q` 行不变，因为姿态角速率不在替换里。**引用任何一个偏导时必须同时写明基底**，否则 `B_long(2,1)` 会被读成"这一轮改了 25 倍"。同理 `lc.A_long(3,2)` 是 `dqdot/dalpha`（每弧度），机体轴的 `dqdot/dw` 是 `-28.7258`，比值 `0.040001` 就是 `1/V0`。

`A` 与 `B` 是配平点的雅可比，偏差坐标下原点是平衡点。控制律必须写成

```
u_dev = u_ff + K*([x_ref; 0] - [x_dev; z]),  x_dev = x_abs - x_op,  z = int(C_int*x_dev - r)
u_abs(u_idx_full) = u_star_full(u_idx_full) + u_dev
```

把绝对状态直接喂给这些增益，闭环会停到别处。报告里给出了这种误用下的实际落点与误差。

## 3. LQR

### 3.1 通道与增广

| 通道 | 状态 | 输入 | 增广输出 |
|---|---|---|---|
| 纵向 | `[dV dalpha dq dtheta]` | `[dde dT]` | `dV` |
| 横航向 | `[dbeta dp dr dphi]` | `[dda ddr]` | `dphi` |

增广方式：把被调输出的积分作为一个新状态，`A_aug = [A 0; C 0]`，`B_aug = [B; 0]`，用 `lqr` 解 Riccati 方程。

纵向选 `dV` 而不是 `dtheta` 的理由：推力到速度是这条通道唯一的能量通路，而速度的稳态值受阻力系数影响，阻力是 ESTIMATE 级参数，没有积分就无法把速度稳在指令上；俯仰姿态在参考点自洽的前提下由 `x_ref` 精确给出，不需要再挂一层积分。备选方案（纵向积分改挂 `dtheta`、横航向改挂 `dbeta`）也在报告里给出增益与裕度，便于 Lead 取舍。

### 3.2 权重

`Q` 与 `R` 直接用 `P.lqr.long.q_diag`、`P.lqr.long.r_diag`、`P.lqr.lat.q_diag`、`P.lqr.lat.r_diag`，不改动。积分状态的权重按与它调的那个状态同容差的规则取 `q_int = q_diag(该输出下标)`，这条规则记录在报告里，属于新增项而不是改动项。

### 3.3 自检

两件事都要成立。`lqr` 的解与 `care` 解出的 `R\B'X` 逐元素之差小于 `1e-6`；Riccati 方程残差 `||A'X + XA - XBR^-1B'X + Q||` 在机器量级。闭环极点全部落在左半平面。

### 3.4 稳态误差判据

同一个被调输出上给阶跃。未增广时闭环停在 `x_ss = -(A-BK)^-1 B K x_ref`，与指令有差；增广后积分器强制 `C*x_ss = r`，误差在 `1e-12` 以下。两组数都写进报告。

### 3.5 参考点与前馈

`lqr_reference.m` 解 `A*x_ref + B*u_ff = 0` 且 `C*x_ref = r`，得到自洽的参考状态与非零前馈。配平点本身就是一组解，对应偏差坐标下 `u_ff = 0`、绝对坐标下 `u_star`。两套前馈在报告里分列，不许混用。

### 3.6 裕度

每一路输入单独断环，其余回路保持闭合，断点取在对象输入端：

```
L_j(s) = K_j (sI - A_aug + B_aug(:,k) K_k)^-1 B_aug(:,j),  k 为另一路
```

用 `allmargin` 取增益裕度、相位裕度、延迟裕度，逐个回路报告，同时给出未增广的对照。

## 4. PID 级联

### 4.0 判据口径（2026-10-10 修订，改的是判据不是权重）

这一节的结论与修订前的版本相反，改动的原因是**判据本身在退化量上优化**，不是为了让图形好看。

**速率环的判据。** 内环 `p/q/r` 是近微分通道：`dcgain(Gq) = 0`（`q = dtheta/dt`，稳态非零速率意味着姿态无界），`q` 通道还带原点传输零点。在这类通道上闭环 `-3 dB` 带宽与阶跃响应都退化：

| 通道 | 退化读数 | 真实回路 |
|---|---|---|
| `q/de` | `bandwidth()` 报 75295 rad/s | `|L| = 1.5` 在 8 rad/s |
| `p/da` | 阶跃"超调"报 3141%，且几乎不随增益变化 | 零点 `-0.0017` 与极点 `-0.104` 近相消 |

在这两个量上做搜索会把增益推到稳定边界外。实测：修订前的交付给出 `Kq = +0.600`，而该通道稳定边界在 0.45 附近；V6 的 `pitch_step` 因此测到 66.36% 超调、81.16% 尾振。

判据改为**闭环阻尼**为主，配 **Nyquist 矢量裕度** `min|1 + L(jw)|`。选矢量裕度而不是增益裕度，因为 `Gq` 在 1 到 8 rad/s 之间相位恒定在 `-175.8` 度，相位从不穿越 `-180` 度，增益裕度在整个可用区间都报 `Inf`，看不出逼近边界。工作值 0.50，硬门槛同为 0.50，清不过门槛的通道按未设计交付开口环。

**速率环极性必须搜索，且 `q` 环的答案是负的。** 这一点与直觉相反，是被测出来的：`B_long(3,1) = -216.197`，正升降舵产生负俯仰角加速度，所以正 `q`（抬头）要产生低头力矩需要正升降舵；而 `q_err = q_c - q < 0`，故 `de = Kq*q_err > 0` 要求 `Kq < 0`。实测短周期阻尼比随有符号增益的变化：

| `Kq` | 短周期阻尼比 | 短周期自然频率 |
|---|---|---|
| 开环 | 1.000（两个实极点 `-24.363`、`-53.490`） | — |
| `+0.05` | 0.900 | 21.0 |
| `+0.20` | 0.670 | 17.2 |
| `-0.05` | 0.955 | 44.2 |
| `-0.20` | 0.813 | 54.2 |

正增益把过阻尼的短周期拆成复极点并**降低**阻尼与频率，负增益同时抬高两者。修订前 V6 超调的根因是这个符号，不是增益太大。

**内环穿越频率目标不再取 `P.ctrl.bw.rate_*`。** 冻结值是 `12 / 8 / 5 rad/s`，而该机上 `p`、`q` 两个通道在那些频率处 `|L|` 达不到 1，没有穿越可打。目标改由机体结构模态导出：取短周期与荷兰滚自然频率中较慢者的一半，夹在 `10` 到 `20 rad/s`。rev 10 的荷兰滚是 `14.379`、短周期是 `24.363`，故目标为 `10.0 rad/s`。冻结值仍在报告里逐环对照列出。

**姿态环加微分项，空速与高度环不加。** 内环是纯比例，姿态环看到的是无阻尼二阶对象，单靠 `Kp` 压不住超调。微分滤波时间取 `P.ctrl.rate_filter_tau_s` 的 1 到 3 倍，下限受外环采样时间 `P.sim.Ts_outer` 约束。加上之后 `theta` 环的线性超调从 22.25% 降到 0.98%。空速与高度对象慢且无欠阻尼模态，微分只是噪声增益，故不开放给这两环。

**速率环的直流增益要求已删除**，理由写在 `design_pid.m` 的 `local_cost` 注释里，不复述。

### 4.1 结构与设计规则

内环 `p/q/r` 角速率，外环 `phi/theta` 姿态，最外层 `V` 与 `h`。所有增益由 `lin` 算出，没有手调常数。

| 环 | 比例增益规则 | 积分规则 | 微分 |
|---|---|---|---|
| p/q/r | 闭环阻尼为主判据，矢量裕度 `>= 0.50` | 无积分 | 无 |
| phi/theta | 使回路幅值在 `P.ctrl.bw.att_*` 处等于 1 | 零点置于 `0.5*wc` 或由搜索定 | 有，滤波 `1` 到 `3` 倍 `rate_filter_tau_s` |
| V | 使回路幅值在 `P.ctrl.bw.speed_rad_s` 处等于 1 | 零点置于 `0.2*wc` 或由搜索定 | 无 |
| h | 使回路幅值在 `P.ctrl.bw.height_rad_s` 处等于 1 | 零点置于 `0.5*wc` 或由搜索定 | 无 |

积分只加在 `P.ctrl.int_limit` 定义了限幅的四个环（`phi`、`theta`、`V`、`h`），速率环不加积分，避免内环积分与外环积分嵌套引起windup。

回路极性由搜索定，两种符号都试，取代价更低的一种并记录符号。速率环的极性由 §4.0 的阻尼判据决定，姿态环与 `V`、`h` 由闭环稳定与代价决定。

控制器一律先 `minreal` 再进入回路分析。`tf` 直接构造会留下非最小实现：`Kd = 0` 时是 `Kp*(Tf*s+1)/(Tf*s+1)`，`Ki = 0` 时是 `Kp*s/s`。这些被抵消的极点本身无害，但级联到带积分器的姿态对象之后，它们会以舍入量级漂到原点附近，被稳定性判据读成发散。这是实测踩到的坑，不是理论顾虑。

### 4.1.1 稳定性受限的增益回退

姿态环与高度环的比例增益有一个附加约束：回路必须在闭环极点意义上稳定。这个机上滚转姿态环会抵消螺旋模态赖以稳定的上反效应，增益升高会把螺旋极点推过原点；俯仰对长周期有同类的弱耦合。

搜索规则：从穿越频率规则给出的 `Kp` 出发，按 `1, 0.9, 0.8, ... 0.2` 逐档下调，每档内积分零点比例按 `0.5, 0.25, 0.1, 0.05, 0.02, 0.005, 0` 逐档下调，取第一个使全部闭环极点严格落在左半平面的组合。优先保住比例增益，因为它的位置直接决定 `P.ctrl.bw` 的带宽判据；积分是次要的，被调对象本身已含积分器时，比例控制对阶跃指令的稳态误差仍为零。

用了哪一档、原始值是多少、是否回退，都写进报告。回退不是"为了让图好看改权重"，而是稳定性判据的直接结果，报告里连同扫描数据一起给。

### 4.2 微分项

微分项统一形式 `Kd*s/(1+Tf*s)`，`Tf = P.ctrl.rate_filter_tau_s`。微分项只在相位裕度不足 `design_pid` 的目标值（默认 45 度）时启用，由相位需求闭式解出 `Kd`，然后重解 `Kp` 保持穿越频率。这里的裕度是在**含执行机构一阶延迟**的回路（`P.act.*.tau_s`、`P.prop.esc.tau_s`）上量的，不是裸刚体模型。

### 4.3 抗积分饱和与积分限幅

反算法，增益 `P.ctrl.anti_windup_Kb`。饱和误差取执行机构处的实际值与请求值之差，再按下游回路增益折算回该积分器所在环的输出量，符号随回路增益自带，因此修正方向永远与造成饱和的误差相反。积分状态限幅取 `P.ctrl.int_limit.(环)/该环带宽`，含义是"积分量不得超过持续一个环时间常数的极限误差"。

### 4.4 带宽分离

外环带宽必须明显低于它要指挥的内环，否则内环不能当快速单位增益用。判据取 0.5，即外环带宽不得达到内环的一半。比值用各环闭环 `-3 dB` 带宽实测，与 `P.ctrl.bw` 的目标比值一并报告。

### 4.5 耦合处理

俯仰与偏航：横航向模型自带 `Cn_da`（副翼不利偏航）与 `Cl_dr`，方向舵环带宽低于滚转环，用它压住副翼引起的偏航；首版不做自动协调转弯，偏航通道由驾驶杆直接给速率指令，副翼引起的稳态侧滑与偏航速率在报告里量化。

速度与高度：高度环输出俯仰角指令，速度环输出推力，这是把长周期模态挡在高度环之外的标准配对。两条环带宽只差一倍，是本设计最紧的一处分离，报告里给出实际比值与后果。

## 5. 控制分配

### 5.1 决策量与效力矩阵

决策量 `v = [da; de; dr; dT_rl]`，`dT_rl = T_r - T_l`。效力矩阵在巡航动压处按 `P.aero` 的控制导数构造，并与线性化模型的 `I*B(4:6,:)` 对比，差值与总推力列（`z_thrust_offset` 引起）都写进报告。

### 5.2 优先级

1. 俯仰先解，升降舵是唯一俯仰执行机构，解出后单独限幅，其俯仰残差不向其他通道转移。
2. 滚转与偏航用加权伪逆，副翼与方向舵为主。
3. 差动推力做补充，权重取"方向舵偏航权限比它强多少"的比值，因此只有在副翼与方向舵不够用时才会被用上。

权重按各通道自身限幅归一化，限幅来自 `P.act.*.max_deg`、`P.prop.differential_limit`、`P.prop.esc` 窗口。差分油门可用量按工作点的油门余量取，与 `sizing/sizing_summary.m` 的 `d_effective` 同式。

饱和处理是活跃集：被限幅的通道固定在限幅值，剩余自由度重解残差，最多三轮，最后一律做硬限幅。请求值与实际值都返回，供饱和统计。

### 5.3 V8 差动推力

解析式：

```
N_diff = y_motor * (T_r - T_l) = y_motor * dT
```

`y_motor = P.prop.y_motor`，与 `plant/thrust_moment.m` 的力臂一致。报告给出该式与 `thrust_moment` 在九个差动量级下的一致性，以及差动推力相对方向舵满偏权限的比值。权威数字取 `sizing_summary(P).authority.diff_thrust`。

## 6. 已知薄弱环节

1. 高度环与速度环带宽只差一倍，长周期模态落在两者之间，高度指令会带出速度偏差，反之亦然。
2. 巡航油门很低，差动推力可用权限约为结构上限的六分之一，不能当作常规偏航手段。
3. 单发失效偏航力矩远超方向舵权限，本机不是单发可巡航的，控制器不承担失效配平。
4. 副翼引起的偏航依赖方向舵环压制，首版没有协调转弯，稳态侧滑会随滚转指令出现。
5. LQR 参考点依赖线性模型的自洽解，超出小角度假设的指令（大俯仰、大滚转）需要用非线性配平重新给参考。
6. 分配器的效力矩阵在巡航动压处冻结，速度大幅偏离时力矩重构误差会随动压变化，分配器不做增益调度。
7. `r` 环的线性矢量裕度只到 `0.5193`，线性穿越频率 `0.2506 rad/s`，是三个速率环里唯一贴着门槛的一个。该通道对象 `Gr` 带右半平面零点 `+0.820 +/- 0.461i`，且 `|Gr|` 在 `w -> 0` 处取峰值 `2.311`，整条回路的可达带宽为零。V6 的实测结果是 `yaw_rate_step` 上升 `0.0550 s`、超调 `176.27%`、尾振 `1041.9%`，即这个闭环在非线性模型上振铃，线性判据没有预见。该通道应当按未设计交付开口环，或者在 `sim` 侧把偏航速率指令通道断开。
8. `p`、`q` 两个速率环的闭环带宽与阶跃响应在这个对象上退化，报告里的 `bw` 与 `os` 对这两环记 `NaN`，有效读数是 `wcp_rad_s`。下游任何按 `bandwidth_rad_s` 取数的脚本都要先判断这一列。
9. `local_vector_margin` 与代价函数里的 `m.sm` 用两条不同的路径算同一个量（前者走 `freqresp(C*G)`，后者走缓存的多项式对），实测在 `r` 环上给出 `0.5193` 与 `0.4370` 两个值。设计用的是后者，报告印的是前者。这一处口径不统一尚未修，任何引用 `vector_margin` 的判据都要以代价函数里的值为准。
10. `q` 环的增益是负的（`-0.863454`），`r` 环也是负的。这是 §4.0 的符号推导与阻尼扫描的结论，但任何按"正增益即负反馈"直觉读这份增益表的人都会以为接线反了。`sim/sim_push_design_vars.m` 已经发布 `sim_pid_<loop>_pol`，模型里有对应的极性块，不需要改接线。
11. **`r` 环按未设计交付，这是 V6 的 `r` 与 `phi` 两条 FAIL 的共同根因。** 实测（`results/sim_manual_pid_traj.mat` 的 `roll_step`，`r` 增益 `-0.896236`）：`phi_c` 是干净的阶跃（2.00 s 起，2.08 s 到 99% 幅值），`phi` 先正确上升到 `1.26°`，随后反向并一路发散到 `-95.00°`。同一时刻方向舵被钉在限幅 `25.0000°`（`P.act.rudder.max_deg`），侧滑角涨到 `9.01°`，副翼掉到 `0`。机理：`r` 通道对象带右半平面零点、可达带宽为零，闭环把荷兰滚放大成满舵，满舵产生大侧滑，侧滑产生的滚转力矩压过副翼，把滚转通道带反。**所以 `r` 开口不是为了让 V6 好看，而是 `phi` 能工作的前提。** 方向舵要可用需要提高 `Cn_r` 或加大方向舵面积，属对象侧改动。
12. 同一次实测暴露的第二个问题：滚转力矩指令峰值 `M_cmd` 的 L 分量到 `1695.53 N*m`，而副翼权限只有 `123.98 * 0.436332 = 54.10 N*m`，即指令是权限的 **31 倍**。分配器在这种不可达指令下的解是 `da = 0`、`dr = 25°`、两侧油门在 `0` 与 `1` 之间跳变，比不用分配器更糟。**分配器缺少"指令超出权限时如何退化"的规则。** 这一条与 §5 的活跃集处理是两件事：活跃集解决"限幅后残差怎么重解"，不解决"指令本身大 31 倍"。
13. `phi` 环的线性预测（上升 `0.5775 s`）与非线性实测（`4.8975 s`）差 8.5 倍，且**不随增益变化**（旧增益下 `5.4725 s`）。结合第 11 条，这个差不是判据口径问题：V6 的 `phi` 条目量的是 `cmd(:,1)` 与 `x(:,7)` 的阶跃响应，指令确是阶跃，判据本身成立；差的是被控对象在满舵侧滑下的真实行为，线性模型里没有这一项。
