## rev 7 → rev 9 的实质变化

**rev 8**：总重 20.0 → **17.0 kg**（载荷按团队要求固定 12.0 kg，机身与系统预算 5.0 kg）；峰值电功率 3500 → **1500 W 每电机**（0.17 kg 的电机带不动 3.5 kW）。

**rev 9**：平尾面积比 0.10 → **0.16**（`Sh 0.3699 m²`，`Vh 0.45882`）。rev 8 的 0.10 使升降舵在 **17.98 m/s** 就打满 80% 行程，远高于失速 9.41 m/s，等于把可用低速边界卡在 18 m/s。实测权衡：

| Sh/S | 可配平最低速 | 静稳定余量 |
|---|---|---|
| 0.10 | 17.98 m/s | 51% |
| 0.14 | 16.01 | 63% |
| **0.16** | **15.28** | **69%** |
| 0.18 | 14.66 | 74%（超出 70% 断言带，否决） |

**要写进报告的结论：**

1. **单发失效从不可控变成可控，但裕度只有 5%。** 满油门单发偏航力矩 47.94 N·m 对方向舵权限 50.11 N·m，比值 0.957，`V_mc` 24.45 m/s **低于巡航 25 m/s**。这意味着**满油门单发只在 24.45 m/s 以上可控**，低于该速度必须收油门。失效处置程序按这条写。
2. **`V_min` 由配平决定，不由失速决定。** 失速口径 11.29 m/s，配平口径 **15.47 m/s**，取后者。**不要报 11.29。**
3. **`L/D` 下降是真实物理，不是公式错误。** 25 m/s 远高于最佳 L/D 速度（约 15.6 m/s），减重使 CL 从 0.222 降到 0.188、更远离最佳点。复核：CL 0.18836、CD 0.032896、阻力 29.115 N、轴功率 727.9 W、`eta_total = 0.602`、电功率 1209.3 W，与报告逐项一致。
4. **静稳定余量 68.6%，在断言带（5..70%）边缘。** 机身预算只有 5 kg 使 CG 前移到 x = -0.15765 m，而平尾按配平需求定尺。想降余量要**重新配平质量分布**（电池与设备后移），缩平尾会立刻吃掉低速配平余量，两者互斥。
5. **纵向短周期已变成过阻尼**：两个实极点 −53.49 与 −24.36，所以模态命名逻辑把真实的长周期（0.4315 rad/s）错标成 `short_period`。这是**命名缺陷**，判据读数会受影响，物理本身正确。

## V12 交叉验证的结论（2026-10-10，rev 9）

用 Aerospace Blockset `6DOF (Euler Angles)` 搭独立对照模型，同一串指令喂两个模型。**判据配置（常密度）四阶段全绿：**

| 配置 | 对峰峰 | 对参考尺度 | 判读 |
|---|---|---|---|
| 常密度，操纵面双t | **9.12e-17** | 9.47e-17 | 判据配置，阈值 1e-4，余量 12 个数量级 |
| 常密度，固定升降舵与油门 | **2.54e-16** | 1.04e-17 | 机器精度 |
| 5 m/s 侧风 | 5.37e-16 | 1.11e-16 | 修坐标系项后落入积分器量级 |
| ISA 大气，两侧都冻结 150 m | 1.25e-16 | 1.89e-16 | 加 ISA 后落入积分器量级 |
| **ISA 随高度（最差一条）** | **2.22e-14** | 2.84e-16 | **引用 V12 时必须带上这一条**，只引 9.12e-17 会低估最差情形 |

**结论一：自写 6DOF 的平动与转动动力学是对的。** 常密度、有操纵输入时与 MathWorks 实现逐位一致（1e-16，比 V10 的 1.9e-8 还严 9 个数量级），末值差全为 0。这是本台架能拿到的最强独立证据。

**结论二：ISA 与侧风两栏的大比值是"分母退化"，不是发散。**
定直飞时高度几乎不动，`ptp(pd)` 只有 0.530 m 而绝对差 0.831 m，比值必然 >1。换成状态的参考尺度后是 **1.1% 与 1.3%**。逐时刻检查显示是**线性缓慢累积后饱和**（相邻区间增长倍率 0.94/1.76/1.23/1.55/1.11/1.01），**不是指数放大**，与"密度低 1.4% → 力低 1.4% → 轨迹缓慢分离"一致。`sim_v12_measure` 已加入"对参考尺度"一列，避免再被大比值误导。

**结论三：发现并已修复一个真实的坐标系缺项缺陷。**
`sim/sim_plant_rhs.m` 在模型边界做空气相对速度变换（`x_air(1:3) = x(1:3) - R*wind_ned`），**风确实进了气动**。但它把 `eom_6dof` 返回的 `d v_air/dt` 当成 `d v_g/dt` 直接用，**漏了 `-ω×(R·W)` 一项**。文件头注释写"the omega x (R*W) terms cancel"是错的。独立实测：

```
dx(1:3) 原样返回    [0.72360585  0.65113233  3.3205606 ]
omega x (R*W)       [-0.0007712092 0.0090702245 0.026531607]
应有 d v_g/dt       [0.72437706  0.64206211  3.294029]
残差 |dx - dv_g_pred - term| = 4.862e-17   ← 恒等式成立
残差 |dx - dv_g_pred|        = 2.805e-02   ← 缺项量级
```

**已修复（`ash-atmo`）**：`dx(1:3)` 补上该减项。修后判据：`dx − 地面系方程` 在十二个分量上最差 **2.220e-16**（修前缺项是 `[-0.15 0 0.3]`）；侧风配置 4.71e-01 → **5.37e-16**。回退证据是**逐位相同（0.000e+00）**，因为该减项在零风时恒为零。

注：`dx(10:12) = R' * x(1:3)` 那一处是正确的（位置运动学要用**地速**，且它覆盖了 `eom_6dof` 用空速算的那一路）。

**结论四：大气常密度已升级为 ISA 密度高度（已修）。** 原 `flow_state.m` 硬编码 `rho = P.env.rho_sl`（实测 qbar 反推 `rho = 1.225000000`）。现由 `P.atmo.model` 选择：`'const'`（默认，保持 rev 9 行为）或 `'isa'`（按高度，`plant/atmo_isa.m`）。与 Aerospace Blockset 的 `ISA Atmosphere Model` 块在有效域内最大相对差 **7.42e-16**，其中 114 点逐位相同。**海平面以下钳位**，与块一致（20 个负高度点差恰为 `0.000000e+00`）。

**结论五：R2024a 的 6DOF 块有 7 个输出端口**，在线文档是 R2026b（加速度口已删）。端口映射由数值定标实测得出，**不是照文档抄的**：`x(1:3)=端口5、x(4:6)=端口6、x(7:9)=端口3、x(10:12)=端口2`，端口 4 的 DCM 与 `sim_dcm` 逐元素差 0。另外该块把欧拉角**卷到 (−π,π]**，实测 φ 在 t=0.5175/1.2175/1.6375 s 各跳 −2π；姿态本身相同，只是表示不同——**引用该块的角度必须按模 2π 比**。

**V12 这一轮的价值在于：结论三那个坐标系缺项不报错、不发散，只是让侧风与密度高度两个场景静默地差 1% 量级。没有第三方实现对照，它不会被发现。**

## 一个曾被误判为"矛盾"的问题，已查清并排除（留档防重犯）

我一度报告"线性化与非线性对象在 q 环上矛盾"：线性化预测 q 指数发散（闭环系数 +118.6），而非线性轨迹稳定。**这个矛盾不存在，是我的代数错误。**

**我的错**：模型接线是 `de = Kp*err`、`err = q_c - q`，所以 `d(de)/dq = -Kp = +0.863454`，**不是 `Kp`**。我用 `d(de)/dq = Kp = -0.863454` 算，把负号用反了一次，于是得到 +118.6 而非正确值：

```
dqdot/dq = A_long(3,3) + B_long(3,1)*d(de)/dq
         = -68.096157 + (-216.196878)*(+0.863454)
         = -254.772216        稳定，比开环 -68.096 强 3.74 倍
```

与非线性轨迹上 q 单调衰减完全一致。**所以 `theta` 与 `h` 的 V6 PASS 站得住。**

**附带两处更正**：

1. `-68.0962` 是 `A_long(3,3)`（`dqdot/dq`），**不是 `(3,2)`**。`A_long(3,2) = -718.125` 是 `dqdot/dalpha`。数值我取对了，列号错了，而列号正是让这个问题看起来牵扯到 `w` 通道的原因。
2. `B_long(:,1)` 的 `-0.254243 / -1.007097` 与 `-0.387497 / -25.175727` **是同一个偏导的两套基底**，不是有人改过 `linearize_at`：
   - 机体轴 `du/de = -0.387497` 对契约轴 `dV/de = -0.254243`
   - 机体轴 `dw/de = -25.175727` 对契约轴 `dalpha/de = -1.007097`
   - **两行的比值都是 `1/V0 = 0.04`（V0 = 25.0）**，`V0` 因子就是全部差别

**引用任何偏导必须同时写明基底**，这条已写进 `docs/design_notes_control.md` §2 与契约。

**排除这个误判所用的硬证据方法值得留档**：在**非线性对象上直接测偏导**（固定状态、只加小扰动、跑一步 `eom_6dof`，完全不经过 `linearize_at`）：

```
非线性 dqdot/dq  = -68.096157   线性化 A_long(3,3) = -68.096157   比值 1.000000
非线性 dqdot/dde = -216.196878  线性化 B_long(3,1) = -216.196878  比值 1.000000
```

**判"线性化是否与非线性同源"只能用这个方法**，不能用另一段线性化代码去核对线性化。

## `phi` 环 FAIL 的根因：指令超出权限 31 倍，且没有限幅（实测数据链）

这一条推翻了两个假设（包括我的"判据口径"假设），根因是**结构性的：外层姿态环产生无界速率指令，分配器没有不可达退化规则**。

**数据链（全部实测，来自 `results/_phi_trace.log` 与 `results/_phi_deep.log`）：**

| 环节 | 数值 | 判定 |
|---|---|---|
| 侧杆指令 `phi_c` | 13.5 deg（**确为阶跃**，2.08 s 到 99%） | 判据口径正确，不该改 |
| `phi` 环增益 `Kp` | 5.938286，无输出限幅 | 外层环无权限意识 |
| `p_c` 需求（零误差处） | 5.9383 × 0.2356 = **1.3992 rad/s** | |
| `p_c` 实测峰值 | **17.7326 rad/s** | 无界 |
| 机体可达稳态滚转率 `p_ss` | **0.6822 rad/s** | 由 `Cl_da/Cl_p` 平衡算出 |
| **需求 / 机体可达** | **26.0 倍** | |
| `M_cmd` 滚转峰值 | **1695.53 N·m** | |
| 副翼滚转权限 | **54.10 N·m** | |
| **指令 / 权限** | **31.3 倍** | 指令物理上不可实现 |
| `M_cmd` 偏航峰值 / 方向舵权限 | 245.79 / 50.11 N·m = **4.9 倍** | 同样不可实现 |

**实测后果**：`phi` 先正确升到 1.26 度，随后**反向发散到 −95 度（倒扣）**；副翼在 t=2.06 之后**掉到 0 并一直为 0**；方向舵钉在 25 度限幅；侧滑涨到 9.0 度；`P.ctrl` 里**没有 `rate_cmd_limit` 字段**。

**两处结构缺陷，是两件事：**

1. **外层姿态环无界。** `p_c = Kp*(phi_c - phi) + Ki*i_phi`，任何姿态误差都变成任意大的速率指令。缺一个按机体可达速率（`p_ss = 0.68 rad/s`）导出的 `p_c` 限幅。**这是 V6 的 `phi` 条目 FAIL 的直接原因。**
2. **分配器缺"指令不可达时如何退化"的规则。** 活跃集处理的是"限幅后残差怎么重解"，**不处理"指令本身大 31 倍"**。实测它在 31 倍不可达指令下把全部权限给了偏航、副翼一个不给，而副翼正是滚转指令最需要的通道——退化方向是错的。

**关于 `r` 环开口**：`ash-control2` 提出 `r` 开口是检验 `phi` 的前提。我独立复核了 `r` 环的符号链，**结论是 `r` 环本身是阻尼的**：

```
A_lat(3,3) = d(rdot)/dr  = -22.04410
B_lat(3,2) = d(rdot)/ddr = -55.46430
模型施加 dr = -0.896236*(r_c - r)  =>  d(dr)/dr = +0.896236
闭环 rdot/r = -22.04410 + (-55.46430)(+0.896236) = -71.75318   稳定，比开环强 3.3 倍
```

逐点验证也显示四种 `r0` 下偏航加速度都指向零点（阻尼）。**所以 `r` 环不是把 `phi` 带反的原因。** `r` 环真正的问题是它在**不可达的偏航状态下**把方向舵钉死在限幅，而那是分配器缺陷的下游后果。

**注意区分**：`r` 的反向发散与 `q` 环那次不同——`q` 那次是真的符号问题（我算错过一次），`r` 这次符号是对的。**两件事要分别结论，不要合并。**

## 三处曾导致判据误判的问题，全部查清

**一、`phi` 环 FAIL 的根因是指令超出权限 31 倍，不是控制律。** 外层姿态环是无界比例律，`p_c = Kp*(phi_c - phi)` 在侧杆到底时要求 **1.3992 rad/s**，实测峰值冲到 **17.7326 rad/s**，而机体可达稳态滚转率只有 **0.6822 rad/s**（26 倍）；对应的 `M_cmd` 滚转峰值 1695.53 N·m 是副翼权限 54.10 N·m 的 **31.3 倍**。修法是按机体可达速率导出的限幅（滚转 0.4776、俯仰 1.1678、偏航 0.3923 rad/s，见 `P.ctrl.rate_cmd_limit`，由 `P.ctrl.rate_cmd_frac = 0.70` 打折）。**一处修复同时解决了 phi、r 两个环**：phi 的 rise 4.8975 → 0.7550 s、err 1.908 → 0.0096；r 的 os 198.20% → 0.48%。副翼与方向舵都不再饱和（峰值 12.08°/45° 与 5.40°/25°），侧滑峰值从 9.0° 降到 2.91°。

**二、V9 的 FAIL 是两个独立错误叠加。**
- **初值错**：侧风场景此前用静风配平点当初值，开局带 `beta = -asin(5/25) = -11.54 deg` 侧滑，测的是初值恢复而不是风扰响应。改用 `plant/wind_trim.m` 的蟹行配平后，**高度残差从 1455.1068 m 降到 2.2262 m**。
- **判据错**：旧残差式 `(pe_w - pe_n) - wind_e*t` 假设风况从静风起飞、因此会先出现完整的 5 m/s 运动学漂移再被减去。蟹行初值下这个漂移**已被气动抵消**，于是该式凭空虚减了 30 秒 × 5 m/s = 150 m 的位移。改为"风况自身东向位移相对其初始位置"后，航迹误差 0.0000 m。

**三、`r` 环的符号是对的（不要与 `q` 环那次混为一谈）。** 我复核过：`A_lat(3,3) = -22.04410`、`B_lat(3,2) = -55.46430`、模型施加 `dr = -0.896236*(r_c - r)` 使 `d(dr)/dr = +0.896236`，闭环 `rdot/r = -71.75318`，**是阻尼的**。`r` 环原先表现差是限幅缺失的下游后果，不是符号问题。

## 本轮修掉的真缺陷（摘要，详见 `docs/acceptance_report.md`）

1. `sim_clear_model` 把容器自己一起删掉，导致其后删除子块报「Invalid Simulink object name」。`find_system(...,'SearchDepth',1)` 在子系统上会把子系统本身列为第一个元素。
2. 同一函数的 `find_system` 选项顺序错误：`FindAll` 写在参数名对之后会被当成块参数，静默返回零条线，所有删线操作变成空操作。
3. `Discrete-Time Integrator` 的 `gainval` 要求严格为正，而 `Ki = 0` 是合法设计结果（纯 PD 环），被拒。
4. `sim_run_model` 没有给输出端口信号命名，导出的信号标签全为空，`sim_read_yout` 回退成 `out1..outN`，所有按名字取信号的场景脚本全部失败。
5. `verify/v_sim_v11_models.m`（以及后面的巡检）用 `exist(f,'file') == 2` 判 `.slx` 是否存在，而 MATLAB 对 `.slx` 返回 **4**（Simulink 模型），导致模型明明在盘上却报「not on disk」。
6. `run_scenarios` 的 V10 分支用 `T4.x` / `T45.x` 取状态，实际字段是 `by_name.x_state`。
7. `run_scenarios` 的 V9 分支用 `w.T.by_name.x_state`，同一处另有 `x_state` 与 `x` 混用。
