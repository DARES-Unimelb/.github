一、验活通道说明
- 工具 web_fetch 对 www.mathworks.com 返回 HTTP 403，正文为 Akamai 的 Access Denied 页。同一工具对 https://example.com/ 返回 200，说明是目标站按 User-Agent 拒绝，不是网络不通。
- 因此 MathWorks 域名的验活改走本目录 _doc_urlcheck.mjs，使用浏览器 User-Agent、follow 重定向、记录 HTTP 状态与去标签后的正文长度。同一批地址当天可重复得到相同状态。
- 结论只以上述通道的 HTTP 200 且正文长度大于 2000 字符为准。仅 200 但正文极短的不算验活通过。
