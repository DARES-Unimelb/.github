## 2. 风：地速与空速怎么分

风的进入点只有一个，在模型边界 `sim/sim_plant_rhs.m`，不在 `eom_6dof` 里。

```
Wb      = C_nb * wind_ned        机体轴风，C_nb = sim_dcm(phi,theta,psi)
v_g     = x(1:3)                 状态里存的是地速，机体轴
v_air   = v_g - Wb               交给 plant 的空气相对速度
d(v_g)/dt = d(v_air)/dt - omega x (R*W)
```

`eom_6dof` 拿到 `v_air`，返回的是 `d(v_air)/dt`，而积分的是 `v_g`，两者差一项。
rev 9 把 `d(v_air)/dt` 直接当地速导数用，缺的就是 `omega x (R*W)`。
实测该项在 `omega = [0.06 -0.04 0.03] rad/s`、`wind = [0 5 0]` m/s 时是 `[-0.15 0 0.3]`，量级 0.3；判据是补项后 `|dx(1:3) - Newton(地速)| = 2.2e-16`，不补是 0.3，见 `results/atmo_wind_report.txt` 的 C1。

**位置运动学不改成空速。** `dx(10:12) = C_bn * v_g` 用的是地速，风把飞机吹过地面但不改变空速，风的效应已经在气动力里，位置这一路再算一次就是重复计入。
判据：`dx(10:12)` 对 `C_bn*v_g` 的差是 0.000e+00，对 `C_bn*v_air` 的差是 5.0，见 C1；常量风下机体姿态与角速率与静风逐位相同，东向位置恰好多出 `W_e*t = 25.000000000 m`，见 C3。

时间变化的风沿用既有通道：`sim/sim_push_scenario.m` 把 `[t wn we wd]` 矩阵推成 `sim_wind_ts`，经 From Workspace 进 `uacs_plant` 的风输入口，`sim_plant_sfun` 每个求解步取一个采样点交给 `sim_plant_rhs`。
`P.atmo.wind_ned` 是 plant 级研究的稳态值，冻结参数集里是零，Simulink 通路不读它。

## 3. ISA 密度高度

公式取 ISA 对流层，静止大气与流体静力平衡：

```
T   = T_sl + dT_sl - L*h
p   = p_sl * (T/(T_sl + dT_sl))^(g/(L*R))
rho = rho_sl * (T_sl/(T_sl + dT_sl)) * (T/(T_sl + dT_sl))^(g/(L*R) - 1)
a   = sqrt(gamma_air * R * T)
```

常数与出处：`T_sl = 288.15 K`、`p_sl = 101325 Pa`、`rho_sl = 1.225 kg/m^3`、`L = 0.0065 K/m`、`g = 9.80665 m/s^2` 取 ICAO 国际标准大气与 ISO 2533 的海平面值；`gamma_air = 1.4`。
`R = 287.0531 J/(kg*K)` **由实测确定**，不是照抄教科书：用常见的 287.05，150 m 处密度比 Aerospace Blockset 的 `ISA Atmosphere Model` 块低 1.9e-7 相对，那是两套密度律而不是舍入误差，V12 会把这个差读成轨迹差。
海平面密度用表值 1.225，不用 `p_sl/(R*T_sl) = 1.22494`，因为标准本身的海平面密度是独立表值，`P.env` 里其余常数都以它为准。

判据：`plant/atmo_isa.m` 与 Aerospace Blockset 的 `ISA Atmosphere Model` 块在 0 m、150 m、1000 m 三点的密度、温度、压力、声速**逐位相同**，相对差 0.000e+00，见 `results/atmo_wind_report.txt` 的 A 段。
`ash-v12` 后来把定标扩成 -50 到 1000 m 的 182 点细扫，本作业按同一张高度表独立复算，分段结论：

| 段 | 点数 | rho 最大相对差 | T | p | a | 逐位相同的密度 |
|---|---|---|---|---|---|---|
| h >= 0 | 162 | 7.420e-16 | 0.000e+00 | 7.446e-16 | 0.000e+00 | 94 of 162 |
| h < 0 | 20 | 4.809e-03 | — | — | — | 0 of 20 |

**海平面以下的分叉是块的饱和，不是公式差**：把块在 -50.0 到 -2.5 m 的取值取出来看，**20 个点全部恰好等于 1.225**，也就是块把自己的高度入口钳在 0 m，而 `atmo_isa` 继续按递减率延伸。判据把这一条证成事实而不是假设，逐点打印块值。
飞行包线在 0 m 以上，两套实现在包线内是同一流体，最大相对差 7.4e-16；包线以下的分叉记在案，将来若有场景飞到参考高度以下，必须在"块给海平面密度"与"我们给更密的空气"之间选一个说法。
`h = 0` 时密度严格等于 `P.env.rho_sl`，所以 V12 的 `const_density` 配置与参考模型仍然是同一种流体。
对流层以上不实现，`h > P.env.h_trop_m` 直接报错，不静默外插；本机包线 `limits.h_max_m` 只有 400 m。

`dT_sl` 保持海平面压力不变、整体抬升温度廓线，也就是通常说的 ISA 加温：同高度上热天更稀。温度抬升而密度不乘 `T_sl/(T_sl + dT_sl)` 会让热天更密，符号是反的，所以这个因子不是装饰。
`dT_sl = 0` 时该因子严格等于 1，三条式子退化成标准形式，逐位一致性不受影响。

`P.atmo.model` 取值 `'const'` 或 `'isa'`，冻结集里是 `'const'`。

## 7. V_mc 与速度包线在 150 m 的修正（安全相关，`ash-atmo` 实测）

**结论先说：现行报告里的 `V_mc = 24.4527 m/s` 与整条速度包线都是海平面值，不是 150 m 飞行高度上的值。**

静的推力标度由动量理论给出，指数是 **1/3** 而不是 2/3：由 `T = (P_shaft*FM*sqrt(2*rho*A))^(2/3)` 得 `T ∝ rho^(1/3)`；2/3 是轴功率的指数，容易误当成密度指数。
本作业直接测量该指数：`T_static` 由 53.271461 N 降到 53.015932 N，反解出的指数是 **0.333333**，见 `results/atmo_wind_report.txt` 的 F 段。

| 量 | 海平面 | 150 m，推力映射按现状仍用 `rho_sl` | 150 m，推力映射用当地密度 |
|---|---|---|---|
| 单机静推 | 53.271461 N | 53.271461 N | 53.015932 N |
| `V_mc` | 24.452667 m/s | **24.629668 m/s** | **24.570526 m/s** |
| 对巡航 25.0 m/s 的裕度 | 2.189% | **1.481%** | **1.718%** |
| `V_stall` | 9.408319 m/s | 9.476421 m/s | 同左 |
| `V_min_trim` | 15.466467 m/s | **15.578421 m/s** | 同左 |
| `V_top` | 30.966467 m/s | 30.966467 m/s | 30.966467 m/s |
| `V_max = 30.0` 可达 | 是 | 是 | 是 |

- `V_mc` 的物理修正量相对声明值是 **+0.1179 m/s（+0.482%）**。按现状实现（推力仍取海平面）更大，是 +0.1770 m/s（+0.724%），因为机翼变薄的同时把方向舵权限按当地密度削掉了 1.43%，而失效发动机的偏航力矩没有跟着降。
- **单发可控裕度从巡航的 2.19% 缩到 1.48% 到 1.72%**，失效处置程序要按 150 m 的值重写。
- `V_min_trim` 升到 **15.578421 m/s**，比海平面高 0.112 m/s（+0.72%）；`V_stall` 升到 9.476421 m/s。
- `V_top` 在 0.5 m/s 的扫描格点上没有变化，说明高度对天花板的影响小于该分辨率；这一项是分辨率受限，不是零效应。
- `V_max = 30.0 m/s` 在 150 m 仍可达。
- 本作业的 `V_min_trim` 二分实现与 `init_uacs_twin` 的存量值比对差 0.000e+00，说明这里的复算与 init 用同一套判据。

修法不在本次范围内，原因是 `prop_thrust_from_throttle` 的密度同时进 `P.prop.speed_table_T`、`P.prop.T_static_max` 与 `init_uacs_twin` 的表一致性断言，属"一张表两处建"的问题。

**限定**：上表是**150 m 巡航高度**的修正量。实际飞行高度不是 150 m 时，`V_mc`、`V_stall`、`V_min_trim`、`V_top` 都要按同一套 `rho^(1/3)` 律重算，`rho` 取 `plant/atmo_isa.m` 在该高度的值；**不要把 150 m 的数当成通用值**。单调方向是明确的：高度升高，密度下降，`V_mc` 与 `V_min_trim` 都单调升高，单发可控裕度单调变小。
另外，按现状实现（推力映射固定海平面密度）比物理一致**更保守**：它把机翼变薄的效果算全了，却没让失效发动机的偏航力矩跟着降，所以 `V_mc` 偏高 0.059 m/s。也就是说现行实现不会低估危险。

## 8. 已知近似

1. **`Cm_alphadot` 按 `alpha_dot = q` 取值**（`plant/aero_forces.m`）。这是静风平飞恒等式 `alpha_dot = q - gamma_dot` 在 `gamma_dot = 0` 时的形式。有风时真实迎角变化率与 `q` 不再相等，定义上不精确；`Cm_alphadot = -2.5` 乘的是一个本身很小的量，且零风平飞下恒等式严格成立。**这是既有近似，不是缺陷**，不要当 bug 再报一遍。
2. **密度模型默认仍是常密度**（`P.atmo.model = 'const'`）。这是冻结 rev 9 行为的开关，不是遗漏；打开后配平、模态与包线数值全部会移动，必须连同报告记录。
3. `trim_cruise` 的 fsolve 初值与内部残差归一化仍按海平面密度算，收敛解与对外报告的 `trim.residual_norm` 都用真实密度。影响仅限于求解路径，ISA 配平残差实测 2.246e-18。

## 9. 侧风配平与蟹行角：已按方案 A 实现

**问题**：`trim_cruise` 的三未知量是 `[alpha; de; throttle]`，约定 `beta = da = dr = 0`、`phi = 0`、`theta = alpha + gamma`。这个配平点是**静风**的。V9 这类侧风场景把静风配平点当初始条件、再把风加到模型上，飞机一开局就带 `beta = -asin(W_e/V) = -asin(5/25) = -11.54 度` 的侧滑，那不是"风扰响应"，而是"初值不在平衡点"的暂态。**V9 之前的 FAIL 里混着这一项，修好 PID 也过不了。**

**关键代数结果（精确成立，不需要新求解器）**：稳态 NED 风下，蟹行配平就是静风配平把航向转过去。
静风平飞配平的机体轴空速为 `V*[cos(alpha); 0; sin(alpha)]`，`theta = alpha`，`phi = 0`，其对 NED 的像只依赖航向：

```
v_a^n = V*[cos(gamma)*cos(psi); cos(gamma)*sin(psi); -sin(gamma)]
```

因为配平的 `alpha` 与 `theta = alpha + gamma` 相消。气动力只依赖 `V, alpha, beta` 与角速率，重力只依赖 `phi, theta`，推力只依赖油门与 `V`，转航向不动其中任何一个，所以 **F = 0、M = 0 逐项严格成立**。
令地面速度 `v_g^n = v_a^n + W` 落在指令航迹 `t` 上，解出

```
s   = (t.W_h) + sqrt((t.W_h)^2 - |W_h|^2 + (V*cos(gamma))^2)
psi = atan2(s*t_E - W_E, s*t_N - W_N)
```

航迹沿北时退化为蟹行角 `psi = -asin(W_E/(V*cos(gamma)))`。需要 `V*cos(gamma) > |W_h|`，做不到时函数报错，不返回不存在的点。

**实现**：`plant/wind_trim.m`，输入静风配平、`wind_ned` 与指令航迹（默认沿北），输出 `x_star`、`u_star` 与航向、蟹行角、地速、升降率。
`trim_cruise` 一个字未改，`init_uacs_twin` 的 `V_min_trim` 二分、`linearize_at`、`sim_v12_trim` 与所有存档配平都不受影响。
零风直接返回输入状态，**逐位相同**，不走方向余弦矩阵的重建路径；两条路差几个末位。
矩阵在文件内自建而不调 `sim/sim_dcm.m`，这样 `plant/` 只靠 `plant/` 与 `params/` 就能用。
