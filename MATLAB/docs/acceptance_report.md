## 2. 核验方法

- 数值结论一律独立复算后复核，不转述他人结论，也不调用被验函数去验它自己。
- 独立复算实现在三个脚本里，都只用 Python 标准库：`results/doc_recompute.py`（2026-10-08 参数）、`results/doc_recompute2.py`（推进模型与单发判据）、`results/doc_recompute3.py`（rev 10，含自写三未知量配平求解器与 850 点设计空间搜索）。常量逐个从 `params/uacs_twin_params.m` 抄入并注明行号。
- 需要 MATLAB 的复核在共享会话锁内执行，证据文件写在 `results/doc_` 前缀下。
- 第三方结论一律回读落盘文件再引用：V12 读 `results/sim_v12_report.txt`，rev 9 到 10 的回退读 `results/atmo_regress_report.txt`，配平基准读 `results/plant_baseline.mat`。
- 源码类结论写明文件与行号。
- 外部引用逐条发请求验活，记录在 `results/doc_link_check.txt`。

### 3.9 单发可控性判据的独立核验

Lead 提出 `|Cn_dr|/Cn_beta` 是单发可控性的真正判据，并给出公开 Aerosonde 参考值 0.945，以及“单纯加大尾翼会恶化单发可控性”这个反直觉结论。我逐条核验，证据 `results/doc_recompute2.txt`。

第一步，参考值核对。`docs/aerosonde_parameters.m.txt` 第 77 行 `C_n_beta = 0.073`，第 89 行 `C_n_delta_r = -0.069`，比值 0.069/0.073 = 0.9452，与 Lead 的 0.945 一致。注意该文件没有写方向舵弦长比，“35% 弦长舵”这个限定不在源文件里。

第二步，当前模型的比值。MATLAB 在库内实测 `abs(P.aero.Cn_dr)/P.aero.Cn_beta = 0.396618`（`results/doc_run_bound.txt`），我的独立代数给 0.396618，逐位一致。

第三步，机理核验，这里是分歧点。按当前文件自己的公式展开：

```
Cn_dr  = -Vv*CY_dr*chord,  CY_dr = k_body*tau_rud*CL_alpha*Sv/S,  Cn_beta = -Vv*CY_beta_tail
比值   = k_body*tau_rud*CL_alpha*(Sv/S)*chord/(0.75) = k_body*tau_rud*CL_alpha*S_rudder/(0.75*S)
```

比值只取决于方向舵面积 `S_rudder = Sv*chord`，与竖直尾翼面积本身无关。三组固定舵面积的算例验证这一点：

| 配置 | 尾翼 | 舵弦比 | 舵面积 | 比值 | `V_mc` |
|---|---|---|---|---|---|
| 0.34 平方米 0.35 弦 | 0.34 | 0.35 | 0.119 | 0.1573 | 63.52 m/s |
| 0.55 平方米 保持舵面积 | 0.55 | 0.216 | 0.119 | 0.1573 | 49.94 m/s |
| 0.90 平方米 保持舵面积 | 0.90 | 0.132 | 0.119 | 0.1573 | 39.04 m/s |

也就是说：尾翼加大而舵面不同步加大，比值一位不变，但 `V_mc` 仍然改善。Lead 的“加大尾翼会恶化”在代码里不成立；成立的版本是“加大尾翼而不加大舵面，等于没加大”。Lead 给出的理由“`Cn_r` 带系数 2、比舵面涨得快”也不成立：`Cn_r` 不出现在 `V_mc` 公式里。

同时给出当前配置与前一步的演化：0.34 平方米配 0.35 弦给 0.1573，0.55 配 0.35 给 0.2545，0.60 配 0.50 给 0.3966，随舵面积单调上升。

第四步，判据口径。严格地说，单发可控性边界由 `V_mc = sqrt(2*T*y_motor/(rho*S*b*|Cn_dr|*dr_max))` 给出，`Cn_beta` 不进入该式。比值的作用是另一个：满舵时平衡所需的侧滑角 `beta = 比值*dr_max`。所以比值是“每单位舵偏需要多少侧滑”的指标，适合当操纵品质基准，不适合当可控性边界。建议判据表里把两者分开写：`V_mc` 判可控性，比值判侧滑品质。

第五步，推进不变量。我在独立实现里复现了 Lead 的四条：功率平衡十个速度点恒为 1609.3000 W，离散度 9.1e-13 W；隐含品质因数恒为 0.550000，离散度 3.3e-16；V=0 油门指数 0.444444 等于 4/9；半功率推力比 0.629960525 与 `2^(-2/3)` 差 1.11e-16。Lead 关于“半功率必得 0.63 倍推力是跨速度错误判据”的说明我认同，我的脚本只在 V=0 做这条检查。

2. `A_long` 的两个实根是 -53.490489 与 -24.363472 rad/s。作为一对过阻尼根，它们的等效固有频率是 `sqrt(l1*l2) = 36.10 rad/s`，与上面的估算差 34.7%，这正是单导数式忽略阻尼耦合时应有的量级。**这才是短周期。**
3. 0.4315 rad/s 与长周期估算 `sqrt(2)*g/V = 0.5547 rad/s` 同量级。**它是长周期。**

所以本布局的真实模态结构是：短周期**过阻尼**，两个实根的时间常数 0.018695 s 与 0.041045 s；长周期是 0.4315 rad/s 的振荡，zeta 0.2209。对一对实根套用"频率落在 2..20 且阻尼大于 0.3"没有意义，因为过阻尼模态没有阻尼比可言（等效阻尼 `(l1+l2)/(2*sqrt(l1*l2)) = 1.0783`）。

报告里那句"单导数估算偏低是预期行为，不是缺陷"在本例方向相反（实测比估算低 98%），说明该注释没有覆盖过阻尼短周期这种情形。

**处置建议**：V4 的短周期判据改成两条分开写。过阻尼时判两个实根的时间常数上限（当前 0.0187 s 与 0.0410 s，都很小，通过）；振荡时判 wn 与 zeta。长周期单独报 wn 与 zeta，不套短周期窗口。`linearize_at` 的模态命名规则也应修正：按"是否振荡 + 与解析估算比对"命名，不要只按"最高的振荡频率"叫短周期。

**V9 的第二个原因：初始条件不在平衡点。** 侧风场景拿**静风配平点**当初始条件再加风，开局就带 `beta = -asin(W_E/V) = -asin(5/25) = -11.54` 度侧滑。那不是风扰响应，是初值不在平衡点，PID 修好也过不了。

**蟹行配平 `plant/wind_trim.m`（方案 A，Lead 已批准并验收）**：稳态 NED 风下的配平就是静风配平把航向转过去，`F = 0`、`M = 0` 逐项严格成立，不需要新求解器，`trim_cruise` 一字未改。用法 `wt = wind_trim(trim, wind_ned, track_deg)`，输出 `x_star`、`u_star`、`psi_deg`、`crab_deg`、`ground_speed_mps`。实测（`results/atmo_wind_report.txt` G 段）：

| 检验 | 结果 |
|---|---|
| 九个动力学状态的归一化力与力矩残差 | 最大 **5.11e-16 / 6.63e-17**（限 1e-12） |
| 与解析航向 `-asin(W_E/(V*cos gamma))` 之差 | 最大 **2.776e-17 rad** |
| 零风退化 | 与输入配平**逐位相同**（`isequal` 为真），原因是**显式短路**而不是数值收敛，见下方说明 |
| 5 m/s 东风、航迹沿北 | 蟹行 **-11.53696 度**，地速 **24.49490 m/s**，飞 5 s 东向位置漂移 **4.441e-15 m**，北向 122.474487 m |

**ISA 块的一条边界行为，记入已知边界**：Aerospace 的 ISA 块把自己的高度入口**饱和在 0 m**，`plant/atmo_isa.m` 不饱和、继续按递减率延伸。

|---|---|---|

| h < 0（-50 到 -2.5 m，20 个高度） | **4.809e-03** | 判定依据：块的 20 个负高度点**全部返回 1.225**，这是取数证实，不是疑似钳位 |

V12 的五种配置全在 h >= 0，结论不受影响。只有将来把场景飞到参考高度以下时才需要选口径。

**零风分支是显式短路**：`wind_trim` 在零风时直接返回输入状态，所以 `isequal` 为真的原因是短路，不是"算出来恰好相等"（一般路径重建状态会差几个末位）。引用时写"零风短路返回输入配平"，不要写"零风下误差为零"。

### D19 `Cm_de` 把尾容量重复计入，**真缺陷、已定位、未修、修正排在 rev 11**

- 影响方向：**偏保守。** `Cm_de` 被低估 2.18 倍，所以报告里的升降舵权限（167.07 N·m）与 `V_min_trim`（15.4665 m/s）都偏保守，真配平能力更强、最低可配平速度应更低。**因此这条不构成安全风险。**

### D20 差动推力字段的含义有误，**待 rev 11 重定义**

- **该字段现在报的是端点值，不是差动推力权限。** `d_effective = min(t_c, 1-t_c)` 在巡航油门小于 0.5 时等于 `t_c`，含义是“低油门那台被压到零”，即**一台停车**，不是差动推力作为常规偏航手段的有效量。
- 第二层问题是线性化近似：`sizing_summary` 用线性律 `2*d*T_static`，而 `T ∝ throttle^(4/9)` 在低油门处斜率大、高油门处斜率小，线性律在巡航点高估约一倍。
- 数值对照：非线性映射下的端点值 **20.3554 N·m**（我的复算）；Lead 一度报 20.83 N·m，用的是他自己手算的巡航油门 0.4465，**该油门是手算错误，已更正为 0.430065**，端点值因此按 **20.36 N·m** 记。线性律会给 42.81 到 47.57 N·m。冻结表写的 40.60 N·m（81.0%）是线性律与端点定义两个错误叠出来的数，**已作废，结论里不得引用 40.60 或 81%**。
- 正确的表述：巡航点差动推力的有效权限应取**小偏差下的局部斜率**。`d = ±0.1` 时推力差 6.66 N，偏航力矩约 **6.0 N·m，等于方向舵权限的 12%**。

### D25 `linearize_at` 的模态命名把长周期叫成短周期，已修复（判据口径缺陷）

- 事实：`plant/linearize_at.m` 的 `local_modes` 把纵向**频率最高的振荡模态**命名为 `short_period`，其余振荡模态叫 `phugoid`。rev 10 下被命名的"短周期"是 wn 0.431531 rad/s、zeta 0.220892、0.0687 Hz，于是 V4 的"短周期 2..20 rad/s 且阻尼大于 0.3"两条都判不过。
- 三条证据说明它指错了模态：
  1. 单导数估算 `sqrt(q*S*cbar*|Cm_alpha|/Iyy) = 26.7978 rad/s`，与 0.4315 差 -98.4%（`plant_modes_report.txt` 第 100 行自己也算了出来）。
  2. `A_long` 的两个实根 -53.490489 与 -24.363472 rad/s，作为过阻尼对的等效固有频率 `sqrt(l1*l2) = 36.10 rad/s`，与估算差 34.7%，正是单导数式忽略阻尼耦合的量级。**这才是短周期。**
  3. 0.4315 rad/s 与长周期估算 `sqrt(2)*g/V = 0.5547 rad/s` 同量级。**它是长周期。**
- 后果：V4 现在会报 FAIL，但那是标签错，不是动力学问题。对一对实根套用"频率窗口 + 阻尼比"本身没有意义，过阻尼模态的等效阻尼 `(l1+l2)/(2*sqrt(l1*l2)) = 1.0783` 大于 1。
- 报告里"单导数估算偏低是预期行为"那句注释在本例方向相反（实测比估算低 98%），说明它没覆盖过阻尼短周期这一情形，也应改。
- 证据：`results/doc_modes_check.py` 与 `results/doc_modes_check.txt`（我从报告打印的矩阵独立复核特征值，最差对称函数失配 2.086e-06 / 2.861e-06，与只印 6 到 7 位相符）。
- 处置建议：V4 的短周期判据改成两条分开写（过阻尼判实根时间常数上限，振荡判 wn 与 zeta），长周期单独报；`linearize_at` 的命名改成按"是否振荡 + 与解析估算比对"判定。
- 修复（Lead，2026-10-10）：`plant/linearize_at.m` 的命名规则改成**按解析估算比对**，并对剩余模态按字符命名（过阻尼带时间常数、振荡带频率）。改后实测：`short_period` lam -24.3635、`phugoid` lam -0.0953 ± 0.4209i、`long_real_tau_0.0187` lam -53.4905。只改标签与命名逻辑，特征值、`A`、`B` 全未动。
